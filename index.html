Immediate AI prompts

Use bounded prompts for technical work and interviewer prompts for behavioral practice. The final decision and answer remain yours.

Repository discovery—do not edit

Do not modify any files. Read the task, README, build configuration and repository structure. Trace the current behavior, cite relevant files and symbols, identify tests and commands, list ambiguities, and propose only the smallest likely change.

TDD RED - do not touch production code

Based on the confirmed acceptance criteria and this repository's test conventions, add the smallest focused failing test for the requested behavior. Explain why it belongs at this test level, run it, show the exact failure, and stop before production changes. If it passes unexpectedly, investigate rather than editing blindly.

Management pressure test

Act as an Atlassian engineering manager. Ask one project-ownership question and interrupt with follow-ups on my personal contribution, business impact, trade-offs, conflict, failure and learning. Do not accept vague “we” statements or invented metrics. Score specificity, scope, judgment and self-awareness only after the mock.

Values pressure test

Act as an Atlassian values interviewer. Select one of the five values without naming it first. Ask one behavioral question and probe the tension, the other person's perspective, what I actually said or did, customer/team impact, and what changed afterward. Flag slogans, hero narratives and answers that are mostly technical.
